# Empreenda Sim

Site institucional do **Empreenda Sim**, uma iniciativa da **WordCom Publicidade e Marketing** voltada ao desenvolvimento de empreendedores e pequenas empresas.

## Criação do projeto

O site foi criado para apresentar, em uma experiência única, os cursos, materiais práticos, comunidade, assistente Cordex IA e eventos presenciais do Empreenda Sim. A página inicial guia o visitante da proposta do ecossistema à assinatura, com seções dedicadas aos especialistas, às trilhas de aprendizado e a uma galeria de fotos dos encontros. Os botões de adesão levam à página do produto na Hotmart.

O desenvolvimento partiu da identidade visual da marca. A alternância entre preto e verde organiza as seções, enquanto a tipografia e as fotografias reais dos eventos dão destaque ao conteúdo. A interface foi estruturada em componentes reutilizáveis, com layouts responsivos e alternativas para quem prefere movimento reduzido.

## Tecnologias utilizadas

| Tecnologia | Papel no projeto |
| --- | --- |
| **Next.js 16** | Estrutura das páginas com App Router, metadados e otimização de imagens. |
| **React 19** | Composição das seções e dos componentes interativos. |
| **TypeScript** | Tipagem dos componentes e dos dados que alimentam a interface. |
| **Tailwind CSS 4, CSS Modules e PostCSS** | Estilos responsivos, paleta compartilhada e estilos específicos de componentes. |
| **Motion** | Transições de conteúdo, entradas suaves e efeitos de paralaxe. |
| **GSAP e @gsap/react** | Animações ligadas à rolagem na galeria e na seção de especialistas, além da entrada dos títulos letra por letra com SplitText. |

A tipografia combina **Bricolage Grotesque** nos títulos e **Inter** nos textos, carregadas com `next/font`.
